Only https://raw.githubusercontent.com/... is accepted. The contract restricts attestation to this one prefix on purpose — a URL you fully control the DNS/hosting for is easier to spoof than a specific pre-named GitHub account. Leave this blank to rely on the check-in timer alone.

Fail-closed by design: if validators can't reach this URL when a release is requested (network issue, page down, GitHub outage), the request is rejected and the vault stays exactly as it was — an outage can never release funds early. It can only ever delay a legitimate release, never cause one it shouldn't.
